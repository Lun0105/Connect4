# Connect 4 四子棋

屏風式四子棋。棋子從每一欄的最下方開始往上堆疊，**最先把四顆棋子連成一線的人獲勝**——橫的、直的、斜的都算。

可以兩個人輪流對戰，也可以一個人跟電腦下。

![遊戲畫面](https://github.com/Lun0105/Connect4/assets/76175876/291f031e-44da-4a96-ba7b-b05444160603)

> 上圖是舊版畫面，新版已改成可直接點擊的圖形棋盤。

---

## 開始遊戲

```bash
python3 main.py
```

不需要安裝任何套件。

## 怎麼玩

| 操作 | 說明 |
|---|---|
| **點擊棋盤** | 棋子會落到該欄最底下的空位 |
| **按 1 ～ 7** | 用鍵盤選欄位落子，效果同上 |
| **按 R** | 重新開一局（也可以點「重新開始」） |

把滑鼠移到棋盤上，上方會出現一顆半透明的棋子，告訴你這一手會落在哪裡，整欄也會跟著亮起來。連成四顆時，那四顆棋子會閃爍標示出來。

**紅色先手，黃色後手。**

## 遊戲設定

畫面上方有三排設定，隨時可以切換（切換後會自動開新局）：

**模式**

- **雙人對戰**——兩個人輪流點同一台電腦
- **人機對戰**——跟電腦下

**難度**（只在人機對戰時可選）

| 難度 | 電腦的強度 |
|---|---|
| **簡單** | 會擋你的四連、也會抓住自己能贏的機會，但不會提前佈局 |
| **普通** | 會往前想幾步，看得出常見的陷阱 |
| **困難** | 會主動佈局做雙重威脅，也會提早閃避你的攻勢 |

難度之間差距很明顯：普通對簡單的實測戰績是 40 比 0，困難對普通是 25 比 15。

**先手**（只在人機對戰時可選）

選「我」就是你先下，選「電腦」就讓電腦先手。四子棋的先手有明顯優勢，想挑戰的話可以讓電腦先。

## 小技巧

- **搶中間**。第 4 欄能參與的連線組合最多，開局先下中間幾乎永遠是好棋。
- **注意你墊的那一顆**。你下的棋子會成為對手的墊腳石——下之前先看一眼正上方那格會不會剛好讓對手連成四顆。
- **做雙重威脅**。同時製造兩個「再一顆就連四」的位置，對手一次只能擋一個。這是贏下困難模式的關鍵。

## 給開發者

遊戲邏輯與介面是分開的，`Connect4Game` 和 `Engine` 不依賴 tkinter，可以單獨 import 來測試或接自己的介面：

```python
from main import Connect4Game, Engine

game = Connect4Game()
game.drop(3)                      # 在第 4 欄落子
print(game.turn, game.winner)     # 換誰下、誰贏了

ai = Engine(depth=5)
game.drop(ai.choose(game.board, game.turn))
```

| 類別 | 職責 |
|---|---|
| `Connect4Game` | 棋盤狀態、落子、勝負判定 |
| `Engine` | AI：negamax + alpha-beta 剪枝 + quiescence search |
| `BoardView` | 棋盤繪製、落子動畫、勝利高亮 |
| `Connect4App` | 版面與遊戲流程 |

棋盤是 `board[欄][列]`，列 0 在最底層，`0` 空、`1` 紅、`2` 黃。

## 執行不起來？

出現 `ModuleNotFoundError: No module named '_tkinter'`，代表你的 Python 編譯時沒有帶到 Tcl/Tk，不是程式的問題。換一個有 Tk 支援的 Python 就好（macOS 上 `brew install python-tk` 或直接用系統的 `/usr/bin/python3`）。
